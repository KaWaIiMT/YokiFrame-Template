# 素材交付与接入规范

> 本文只回答两件事：**人怎么把素材交给 Agent**、**Agent 怎么把素材放进游戏**。
> 具体要哪些素材、长什么样，由策划在 TAPD 里定，不写在这里。

## 1. 素材放哪

```
Assets/Resources/Art/
├── Sprites/   图片：角色 / 背景 / UI / 特效……
├── Fonts/     字体
└── Audio/     音频：BGM / SFX
```

加载走 YokiFrame 的 ResKit，它默认读 `Assets/Resources/`，所以素材必须放在这下面。二级目录随意分，只影响整理，不影响加载。

## 2. 命名

全小写 + 下划线，不用中文、空格。例：`frog_idle_00.png`、`ui_btn_start.png`、`bg_room.png`。多帧用 `_00` `_01` 序号，或直接给 `.aseprite`。

## 3. 交付时跟 Agent 说一句（三件事）

> 「我把 X 放到了 `Art/Sprites/...`，它是 Y，用在 Z。」

例：
- 「青蛙待机 4 帧放 `Art/Sprites/Frog/`，8fps 循环，做待机动画。」
- 「`ui_btn_start.png` 是开始按钮底图，要 9-slice，四边各 20px。」

不用描述画面，Agent 能直接读图。

## 4. Agent 怎么用

1. 读文件、看图，确认内容与用法。
2. `ResKit.Load<Sprite>("Art/Sprites/...")` 按名字加载。
3. 挂到对应的 `Image`（UI）或 `SpriteRenderer`（场景物体），或替换灰块占位。

素材没到位时用灰块兜底，不报错。

## 5. 必须在 Unity 编辑器里手动做的

- Sprite 切片（多图 sheet / 9-slice）：在 Sprite Editor 里切；或把 sheet 丢给 Agent 并说明切片规则，Agent 写 `.meta`。
- 复杂 Prefab / 动画事件与曲线的手动微调。

## 6. 交付自检

- [ ] 在 `Assets/Resources/Art/` 下
- [ ] 命名全小写下划线
- [ ] 给 Agent 说了一句「是什么、用在哪」
